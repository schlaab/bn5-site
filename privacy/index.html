Privacy Policy: Inbox-bridge-mcp

Effective date: November 26, 2026. Operator: bn5.me. Contact: mail@bn5.me.

What this application is

Inbox-bridge-mcp is a private, single-operator tool. It lets the operator read his own Gmail messages and Google Calendar events, across several Google accounts that he owns or that their owners have explicitly authorized, from his own computer. It is not offered to the public and has no other users.

Google user data we access

  • Gmail (gmail.readonly; for two of the operator's own accounts, gmail.modify): message metadata, message content and attachments, used to build the operator's daily summary and to search his own mail. gmail.modify is used only to apply labels, mark messages read and create drafts. The application never sends, trashes or deletes mail.
  • Google Calendar (calendar.readonly): the list of calendars and their events, used to build the operator's daily schedule. The application never creates, changes or deletes events.

How the data is used

Google user data is used only to provide the features above to the account owner who authorized access. It is not used for advertising, is not sold, and is not used to develop, improve or train generalized artificial intelligence or machine learning models.

Storage and security

OAuth tokens are stored in the macOS Keychain on the operator's computer. Mail and calendar data are fetched on demand and held in memory or in short-lived local cache files on that computer; downloaded attachments are stored locally and deleted periodically. Nothing is stored on servers operated by this application.

Sharing

Google user data is not shared with or transferred to third parties, except that the operator may pass excerpts of his own data to an AI assistant he uses on his own behalf to summarize or answer questions about it. No data is shared for any other purpose, and none is transferred to data brokers or advertising services.

Retention and deletion

Tokens remain until access is revoked. Any account owner can revoke access at any time from myaccount.google.com/permissions; revocation stops all access immediately. To request deletion of any locally stored data, email mail@bn5.me; it will be deleted within 30 days.

Google API Services User Data Policy

Inbox-bridge-mcp's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
